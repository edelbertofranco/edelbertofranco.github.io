Entrar

O admin grava o conteúdo direto no repositório edelbertofranco/edelbertofranco.github.io. Ele usa um token do GitHub que fica salvo apenas neste navegador.

Como criar o token (uma vez)
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Nome: "Admin do site"; validade: a que preferir (por exemplo, 1 ano).
  3. Resource owner: edelbertofranco.
  4. Repository access: Only select repositories → edelbertofranco.github.io.
  5. Permissions → Repository: Contents = Read and write; Actions = Read-only (para ver o status da publicação).
  6. Gere o token, copie e cole acima.
